Windows leaf diagnostic

一行检查 Planet、Moon 与公网路径

在管理员 PowerShell 中运行。引导器会从最新 GitHub Release 下载诊断脚本，重启一次本机 ZeroTier，并将完整报告保存到桌面。

Administrator PowerShell 
irm https://guajun.github.io/zerotier-moon-endpoint-updater/run.ps1 | iex

主动探测会让本机 ZeroTier 短暂断开一次。下载内容来自仓库最新 Release，不由网页复制脚本本体。

Clean bootstrap

只把服务重启之后的新收包作为证据，排除旧 Planet 路径造成的假阳性。

Same-protocol control

同时观察香港、深圳 Moon 的 ZeroTier UDP，用来区分 Planet 特定过滤与普通 UDP 故障。

Local report

结果和各段证据写入桌面时间戳文件，便于保留、截图或交给网络服务商。

结果判读

PASS

官方 Planet 在观察窗口内返回了新数据，当前网络环境可以访问 Planet。

SUSPECTED_PLANET_FILTER

Moon 的 ZeroTier UDP 正常，但重启后没有 Planet 回包，疑似 Planet 地址或路由被针对性过滤。

ZEROTIER_UDP_UNAVAILABLE

Planet 和 Moon 都没有新回包，应优先检查 PassWall、防火墙、NAT 与 UDP/9993。

INCONCLUSIVE

证据不足以隔离故障，可延长观察时间并结合报告中的端点和控制探测继续判断。
